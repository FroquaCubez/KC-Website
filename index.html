FAQ

What versions are supported?
We currently support base TU19 and Revelations. For specific version compatibility, please verify in our Discord announcements.
How does the Auth system work?
Unlike older setups, our server generates a unique xuid every time a user signs up on the server side so the user does not need to send their xuid for security.
Cannot connect to the server?
Make sure to read our #faq channel on our discord server
